# User Guide Screenshots

Place screenshot PNG files in this folder using the filenames listed in the [Screenshot Checklist](../USER_GUIDE.md#screenshot-checklist) at the end of `docs/USER_GUIDE.md`.

## Recommended settings

- **Format:** PNG
- **Resolution:** 1280×720 (matches the app design) or native TV capture
- **Naming:** Use the exact filenames from the checklist (e.g. `02-welcome-screen.png`)

## Adding screenshots

1. Capture the screen on your Android TV device or emulator.
2. Save the file here with the matching filename.
3. The user guide already references each path — no edits needed unless you rename files.

Example:

```
docs/user-guide/images/
  01-splash-screen.png
  02-welcome-screen.png
  03-health-safety.png
  ...
```
